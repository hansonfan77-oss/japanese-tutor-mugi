# Mugi 咖啡店五分鐘試用

在家教首頁點「咖啡店語音練習」。每輪先看店員問題，自己試著念，再點「模擬說這句」看範例字幕。五輪依序練內用、品項、冷熱、尺寸與結帳。計時從第一次模擬收音開始，切到背景時暫停。回到畫面後，點「繼續練習」重做被中斷的一輪。完成五輪可提早收工並回看對話，離開會清除這次練習。

## 下階段的真實語音比較

在同一支 Android 手機、同一教室與同一組台詞上，比較手機語音辨識＋小 PC 回覆／地端 VOICEVOX，和經確認可用的另一種語音方案。兩輪都念「カフェラテを一つください」，中途改口一次、打斷一次，再各做一次背景切換與整個 PWA 關閉重開。

| 觀察點 | 記錄方式 |
| --- | --- |
| 聽懂點餐 | 五輪逐項對照品項、冷熱、尺寸。記字幕誤認及需要重說的輪數。 |
| 回覆速度 | 記每輪說完到最終字幕、第一聲回覆的毫秒數，列中位數與最慢一輪。 |
| 打斷與恢復 | 記按下打斷到舊聲停止的時間、殘留字幕或重播次數、回前景後的收音狀態。 |
| 聽感 | 分別評日文發音、語調與斷句，各 1–5 分，記下一個具體例句。 |

測量使用臨時練習句與相對時間。要測真實語音時，再一起確認可用帳號、引擎、單次預算與手機權限。

## 單次費用試算（美元）

本輪模擬服務費為 **$0**。下階段先假設五輪、每輪一個文字回覆，沿用專案每句平均值估算，Haiku 約 **$0.0017**，Opus 約 **$0.0685**。這兩個數字只涵蓋文字。地端 VOICEVOX 的每次供應商 API 費為 $0，電力另計。[估算常數](../src/game/budgetEstimate.ts)

若選按量計費語音，規劃值可用 1.5 分鐘學員語音、500 字元合成量。把當時方案的每分鐘 STT 價格乘 1.5、每百萬字元 TTS 價格乘 0.0005，再加文字費。即時音訊模型則分別以實際輸入及輸出 audio token 計費，需用該模型的計價單位重算。重說、歷史長度與計費進位會影響總額。

## 美術需求（一頁）

先沿用內建教室與 Mugi 原身體。若要加姿勢，交付同畫布、同腳底錨點的透明 WebP，以現有 657 × 768 身體、嘴部對位與六個口形為基準。聆聽時側耳，思考時短暫抬眼，播放時保留原口形，打斷時收口並回到聆聽姿勢。靜止版仍需靠文字辨識狀態。
