# 後續開發規格（本次不實作）

原則：保留目前日語家教工作流、以本機儲存和既有免費能力為先；未經授權不開通付費 API、不將學生資料送新服務。

| 項目 | 最小範圍與資料契約 | 驗收與風險 |
| --- | --- | --- |
| N5～N1+ 自適應 | 明確區分自評級數、單字/文法技能與觀察證據；本機記錄答題正確率、提示次數及最近練習，有限度升降級；N1+ 自訂進階標籤而非官方新級別 | 固定題集回放驗證難度不震盪；無證據不斷言已掌握；保留人工調整 |
| 一問一答/跟讀 | 以練習 session、題目、原文、嘗試、評分來源與完成狀態建模；先文字比對/既有 STT，語音不可用可手動輸入；先重用現有 TTS | 麥克風權限、取消、背景恢復、重播、超時；STT 轉錄不能當作音素發音準確度評分 |
| 進度與複習 | 版本化 IndexedDB，卡片包含下次複習、間隔、成功/失敗歷史；以假時鐘驗證排程；匯出/匯入需使用者主動操作 | 升版遷移、損壞恢復、跨時區、刪除與備份；不同裝置同步是獨立決策，不自動上雲 |
| Ollama 本地 AI | 沿用 LlmProvider 介面，候選模型及量化版本需先記錄授權、RAM、上下文與模型 checksum；只綁 loopback，禁止對任意 URL 開放代理 | Ryzen 7 8745HS/24GB Windows 上量測冷/熱啟動、首 token、tokens/s、記憶體、併發、繁中教學/日語品質及 Structured Output 修復；未知 GPU 不預設可用，不先承諾吞吐 |
| AI 情境背景/快取 | 獨立明確操作，不隨聊天自動生成；本機工具優先；快取鍵含模型版本、prompt 摘要、尺寸與 seed；磁碟上限與 LRU 清理 | 生成時間、GPU/記憶體、來源授權、敏感圖片保護；無可用免費模型時停用，不能偷偷切付費服務 |
| 服裝/動態素材 | 版本化角色素材 manifest；body/head/eyes/mouth/服裝層、pivot、z-index、共同座標、可選嘴型；沿用動畫核心與單圖 fallback | 圖片 MIME/尺寸/總量驗證、素材配準、圖層缺失、角色切換釋放資源；Android/iOS FPS/電量與 reduced-motion 實測 |

建議順序：Windows/手機 M1 驗收 → 接入 M2 分層渲染與效能量測 → 本機進度與固定題練習 → 有基準資料後開發自適應 → Ollama 小模型基準 → 背景與服裝素材工具。每個階段獨立工作分支及驗收，不擴充本次 PR。
